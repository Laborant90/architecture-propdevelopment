Задание 3. Внешние интеграции

I. В файле PropDevelopment_С4_model.drawio.xml находится диаграмма контейнеров

Аннотация
1. Для реализации взаимодействия с внешними сервисами добавлены микросервисы tentant-parking-app и tentant-intercom-app
2. Взаимодействие с внешними сервисами проводится по протоколу https, тем самым обеспечивается шифрование трафика.
3. tentant-parking-app и tentant-intercom-app проверяют наличие токена пользователя (пользователь должен авторизоваться в системе (например через мобильное приложение). В качестве токена можно использовать JWT токен.
4. Микросервисы tentant-parking-app и tentant-intercom-app проверяют токен + роль пользователя (только собственники могут пользоваться возможностями интеллектуального домофона и шлагбаума) + проверяется наличие оплаченной услуги.
5. После успешных проверок микросервисы отправляют запрос во внешние системы, при этом передача данных организована с использованием https + авторизация во внешней системе проводится по данным технологической учётной записи системы (данные хранятся в vault). Биометрическая информация не хранится в БД микросервиса домофона (в БД храним наличие подключенной услуги + историю успешных распознаваний (id пользователя + дата, время). В БД микросервиса шлагбаума храним привязку списка номеров к id пользователя. Для БД включено шифрование данных + данные хранятся в обезличенном виде.
6. Передача данных для аналитики проводится при помощи ETL, при этом запрашиваются только общие данные (например количество пользователей сервиса).
